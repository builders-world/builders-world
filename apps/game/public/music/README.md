# Background music

Put MP3s here and list them in `playlist.json`. Only use tracks whose licence allows use inside a game
(Pixabay Content License does; StreamBeats' free licence does not). Record the source and licence for
each track. Creator mode always plays the game's own generated music instead, so streams stay safe.

```json
{
  "day":   [{ "file": "sunny-accra-groove.mp3", "title": "Sunny Accra Groove", "artist": "Vadim_Makes_Sound", "licence": "Pixabay Content License", "source": "https://pixabay.com/music/afrobeat-sunny-accra-groove-567649/" }],
  "night": []
}
```
