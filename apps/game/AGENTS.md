# Instructions for every agent working on Builders World

Read the world bible in the parent Builders-World repository (`docs/design/world-bible.md`; from this app that is `../../../docs/design/world-bible.md`) before any task. It is the single source of truth for how the world is built: real-world sources, scale and street engineering, level design, art, shaders, game logic, UI, writing and performance. The PRD (`docs/product/builders-world-prd.md`) decides what the product is; the bible decides how it is built.

Coordinate through `/Volumes/Elvis Obi - Mac Extended/Builders-World.collab/` and `docs/collaboration/asset-work-live-handoff.md`. Do not edit another agent's working directory or files it owns without writing the proposal there first. Commit locally; do not push until Elvis says so.

Check your work in the browser before calling it done: `scripts/verify/` (README there). Say what you checked and what you did not.
