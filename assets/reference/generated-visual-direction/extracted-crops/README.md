# Named Yaba reference crops

These crops isolate useful visual direction from the local ChatGPT-generated boards:
street composition, the community-board interaction, the provisional builder silhouette,
materials, and the Explore → Connect → Build loop. They are review and prompting aids;
they are not runtime textures and are not embedded in the GLB exports.

Source files remain in `generated_images/chatgpt-yaba-visual-references/`. The crop script
is `assets/source/reference/make_yaba_reference_crops.py`, so the set can be regenerated
without manual image editing.
