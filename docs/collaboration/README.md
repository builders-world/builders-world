# Collaboration

Start with the root [project handoff](../../PROJECT_HANDOFF.md). It contains the team roster, access history, pending work, and the proposed task/PR workflow.

Use one worktree or clone per active agent and one branch per task. Keep task ownership in an agreed issue or task record, push meaningful progress, and integrate through PRs into `main`. Fetch and read relevant updates before starting work and at handoff boundaries. A Git push does not synchronize the agents' conversations or merge their working directories.

This directory is reserved for durable team agreements and later dated handoffs. Keep task-specific progress with its issue or PR instead of making every contributor edit one shared status file at once. No additional worktrees, automatic synchronization, or repository rules have been created by the folder organization.
