# Technical decisions

Record accepted technical choices here so contributors and agents can recover the reasoning from the repository. No technical decision records have been accepted yet; the directory layout is a proposal.

Use a short descriptive filename, such as `0001-phase-1-stack.md`, with:

- Date and status: proposed, accepted, or superseded.
- Decision owner and related issue or PR.
- Problem and relevant constraints.
- Decision, alternatives considered, and practical consequences.
- Any earlier decision that this one supersedes.

Update the PRD as well when a decision changes product behavior. A proposed record should not silently be treated as an accepted requirement.
