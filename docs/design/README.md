# Design documentation

Use this directory for interaction specifications, design tokens, accessibility decisions, asset conventions, and reviews as they are created.

The current direction is in the [PRD](../product/builders-world-prd.md), with illustrative mockups in the [HTML version](../product/exports/builders-world-prd-v1.0.html). The flat site and admin use a daylight palette with amber accents. The later world uses flat-shaded low-poly forms, cool night colors, and activity-driven amber light.

Store actual visual references in `assets/reference/`, Blender kit sources in `assets/source/blender/building-kit/`, and deliberate model/render exports in `assets/exports/`. Paths in this paragraph are relative to the repository root. No product design assets have been approved or generated by this folder organization.
